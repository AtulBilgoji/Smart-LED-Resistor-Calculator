# Smart LED Resistor Calculator Using C

## 1. Project Overview

The Smart LED Resistor Calculator is a simple C programming project designed to calculate the required series resistance for an LED circuit.

The program takes three inputs:
- Supply Voltage (Vs)
- LED Forward Voltage (Vf)
- LED Current (I)

It calculates the required resistance using the electrical formula and displays the result.

## 2. Project Objective

The main objective is to understand the practical application of C programming in basic electronics calculations.

## 3. Technologies Used

- Programming Language: C
- Compiler: GCC
- IDE: Visual Studio Code
- Operating System: Windows

## 4. Key Features

- Accepts voltage and current inputs.
- Calculates LED series resistance.
- Validates basic input conditions.
- Displays the calculated resistance in Ohms.

## 5. Application

This project is useful for learning basic LED circuit design, Ohm's Law, and C programming fundamentals.

## 6. Project Status

Initial version completed and tested using GCC.
